Frequently Asked Questions

When should I use Base64 images instead of image files?

Base64 is ideal for small UI icons, self-contained email templates, and PWA offline assets where eliminating additional HTTP roundtrips speeds up rendering.

Does Base64 encoding increase file size?

Yes. Base64 encoding typically increases binary file size by approximately 33%, which is why it is best suited for assets under 50 KB.

Are my images uploaded to external servers?

No. Conversion occurs 100% locally in your web browser memory using FileReader. Zero data is transmitted over the network.
