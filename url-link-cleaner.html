What does this tool remove?

Marketers attach strings of text to the end of URLs (called query parameters) to track where you came from. If you copy a link from a Facebook ad or an email newsletter and paste it to a friend, you are dragging that tracking code along with it.

This URL Cleaner uses native URL parsing to safely strip out:

  • UTM parameters: utm_source, utm_medium, utm_campaign
  • Facebook IDs: fbclid
  • Google IDs: gclid, gclsrc
  • Mailchimp IDs: mc_eid
  • Instagram IDs: igshid
