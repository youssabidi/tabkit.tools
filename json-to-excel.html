  2. Verify Column Preview: Check generated worksheet headers and nested field extraction before writing binary workbook data.
  3. Convert & Download .xlsx: Export a real Excel spreadsheet workbook with formula-injection protection applied to string values.

Handling Heterogeneous API JSON Records

Real-world webhook logs and NoSQL exports rarely share identical keys on every item, making union-key discovery critical for complete exports.

  • Union of All Keys vs. Auto Keys: Choose Union of All Keys when optional fields like errorMessage or discountCode only appear on a subset of objects in the array.
  • Excel Cell Character Limit: Microsoft Excel enforces a 32,767-character limit per cell; truncate massive base64 blobs or raw HTML fields before converting if needed.
  • Sanitized Text Cells: Values starting with =, +, -, or @ are automatically protected against formula execution when opened by stakeholders.

Frequently Asked Questions

How does the converter handle nested JSON objects and arrays?

Nested object keys are flattened using dot notation (e.g. user.address.city) into dedicated spreadsheet columns, ensuring no data attributes are omitted during export.

Can I paste raw JSON text or upload a .json file directly?

Both methods are supported. You can paste raw JSON payloads directly into the editor or drag and drop a .json file from your computer.

Is my proprietary API data stored or transmitted?

Never. All parsing and OpenXML file creation happen locally in your web browser. Zero bytes are uploaded to any server or cloud infrastructure.
