CommonMark & HTML Sanitization Practices

Subtle syntax differences between Markdown parsers frequently cause broken lists or misparsed underscores inside technical docs.

  • Blank Lines Around Lists & Fences: Separate paragraphs from bullet lists and ``` code blocks with an empty line so strict CommonMark renderers parse blocks reliably.
  • Fenced Language Hints: Always specify language tags after triple backticks (```js, ```bash, ```json) so GitHub and static site generators apply accurate syntax highlighting.
  • Escaping Literal Asterisks & Underscores: Precede literal underscores outside code spans with a backslash (\_) to avoid accidental italics in snake_case identifiers.
  • HTML Entity Encoding: When documenting code samples containing raw HTML tags like <div> or <span>, escape angle brackets as &lt; and &gt; to prevent browsers from parsing them as live DOM nodes.

Common Pitfalls & Engineering Troubleshooting

Cross-Site Scripting (XSS) via Unsanitized Markdown

Markdown allows raw HTML elements by design. If user-supplied markdown is rendered directly to DOM innerHTML without strict sanitization, malicious actors can inject <script> tags or <img src=x onerror=...> payloads to hijack session tokens. TabKit runs all output through DOMPurify.

GFM Table Header and Delimiter Alignment Breakages

In GitHub Flavored Markdown, tables strictly require a header row followed by a delimiter row containing at least three hyphens per column (|---|---|). Omitting the delimiter row or having mismatched column counts causes the entire table to render as broken plain text.

CommonMark 4-Space Indentation Rules for Nested Lists

In CommonMark, nesting code blocks or secondary paragraphs inside a list item requires 4 spaces or a tab of indentation. Using only 2 spaces breaks the list item continuity and renders the child block at the root level.

LaTeX Math Delimiter Escaping ($ vs \$)

In scientific markdown documents containing KaTeX or MathJax equations, unescaped literal dollar signs in prose (e.g. costs $50 to $100) are misinterpreted as math delimiters, corrupting the formatting of surrounding paragraphs. Always escape literal dollar signs with a backslash (\$).

Footnote Reference Identifier Collisions

Extended markdown engines support academic footnotes using [^1] syntax. When merging multiple document chapters into a single markdown file, duplicate footnote keys overwrite preceding definitions unless unique namespace prefixes are assigned.
